Setup Instructions

1 Run Simulation

Execute your rocket simulation and select the Plot / Export button to proceed.

2 Export Data

In the window that appears, locate and click the Export Data button positioned adjacent to the plot options.

3 Configure Settings

Select the specific checkboxes and configuration settings as illustrated in the reference image below to ensure data compatibility.

4 Visualize

Upload the exported CSV file; your 3D flight visualization will then generate automatically.
